# Final-Project

Comparative study of domain adaptation in Deep Learning models for single-cell segmentation on high-resolution spatial transcriptomics histology images.

This repository contains the source code and analysis for a comparative study on digital cell segmentation within spatial transcriptomics (ST). The primary focus is to analyze the effect of domain adaptation across various deep learning models. By evaluating multiple models, this project aims to improve the accuracy and robustness of single-cell segmentation on high-resolution histology images.
